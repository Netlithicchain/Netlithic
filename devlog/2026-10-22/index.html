What this means for contributors

  • From block 5000 the founder's server stops mining and only relays blocks. Mining moves to the community.
  • Its only exception is a capped backstop block if nobody has mined for 30 minutes.
  • Community reward shares come every 144 blocks from block 5000, with the first at block 5144.
  • The leaderboard and the founder transparency page let anyone check activity in the open.
  • An easier wallet: live balances, clear transfer status, a checked backup, and Share with a QR code.
  • Contacts stay on your device.
  • Rewards are test coins only. Test coins have no value.

In progress and next

  • A trusted, signed Windows installer for the desktop app.
  • The next desktop app build, adding Share and helping stats.
  • An easier node setup and a Linux build.

Known limits

  • The desktop app is coming soon and is not available for public download yet.
  • When it is released, desktop users will need to keep the app updated to stay on the network.
  • Blocks take a few minutes each until block 5000, when the 60-second target starts.
  • The 3-of-5 multisig is built but turned off, and the treasury stays locked.
